BJT කියන්නේ මොකක්ද?

ස්ථර තුනේ semiconductor එක

BJT (Bipolar Junction Transistor) එකක් කියන්නේ semiconductor ස්ථර තුනක් එක පිට එක තියලා හදපු device එකක්. අද තියෙන electronic systems ඔක්කොගේම වගේ පදනම semiconductor devices. ඒ අතරින් ගොඩක් ප්‍රසිද්ධ, ගොඩක් පාවිච්චි වෙන එකක් තමයි BJT. ඒකෙන් ප්‍රධාන රස්සා දෙකක් කරන්න පුළුවන්:

  • Amplifier (පුංචි signal එකක් ලොකු කරන එක): microphone එකක mV signal එකක් speaker එකට ගැලපෙන තරමට ලොකු කරන එක වගේ.
  • Logic switch (ON/OFF කරන ස්විච් එකක්): digital circuit එකක 0 සහ 1 හදන එක වගේ.

ස්ථර තුනට අනුව BJT වර්ග දෙකයි:

  • npn: n ස්ථර 2 ක් සහ p ස්ථර 1 ක්. p එක මැද.
  • pnp: p ස්ථර 2 ක් සහ n ස්ථර 1 ක්. n එක මැද.

Terminals තුනට නම් තියෙනවා: Collector (C) (charges එකතු කරගන්න කෙළවර), Base (B) (පාලනය කරන මැද කොටස), Emitter (E) (charges විදින කෙළවර). Emitter සහ collector දෙකම එකම වර්ගයේ material (npn නම් දෙකම n). Base එක විතරක් අනිත් වර්ගයේ. Base එක මැද තියෙන්නේ, ඒක collector සහ emitter දෙකටම වඩා ගොඩක් සිහින්. ඒ වගේම base එකේ doping (semiconductor එකට එකතු කරන අපද්‍රව්‍ය ප්‍රමාණය) අඩුයි. මේ කරුණු දෙක ඊළඟ කොටසේදී ගොඩක් වැදගත් වෙනවා.

"Bipolar" කියන නම ආවේ ඇයි? (bi = දෙක, polar = ධ්‍රැවීයතාව). BJT එකේ current එක ගෙනියන්නේ charges වර්ග දෙකම: electrons (negative) සහ holes (positive). Emitter එකෙන් ප්‍රතිවිරුද්ධ වර්ගයේ material එකට (base එකට) charges "inject" කරනවා. ඒ ක්‍රියාවලියට holes සහ electrons දෙකම සම්බන්ධ වෙනවා. FET එකක එහෙම නෑ, ඒකේ එක වර්ගයක් විතරයි (unipolar).

BJT එකේ pn junctions දෙකක් තියෙනවා: emitter-base junction (EBJ) සහ collector-base junction (CBJ). එක pn junction එකකට bias කරන්න පුළුවන් විදි දෙකයි:

  • Forward bias (p පැත්තට +, n පැත්තට −; junction එක "ඇරෙනවා", current ගලනවා)
  • Reverse bias (p පැත්තට −, n පැත්තට +; junction එක "වැහෙනවා", current ගලන්නේ නෑ වගේ)

Symbol එකේ ඊතලය කියන දේ

Symbol එක දැක්කම npn ද pnp ද කියලා අඳුනගන්නේ ඊතලයෙන්. ඊතලය ගැන නීති තුනක් තියෙනවා:

  1. ඊතලය හැම වෙලාවෙම emitter එකේ. ඒ නිසා ඊතලය තියෙන කකුල emitter එක කියලා කෙළින්ම කියන්න පුළුවන්.
  2. ඊතලය හැම වෙලාවෙම n-type පැත්තට යොමු වෙලා. npn එකේ emitter එක n නිසා ඊතලය base එකෙන් එළියට (emitter දිහාට). pnp එකේ base එක n නිසා ඊතලය base එක දිහාට, ඇතුළට.
  3. ඊතලය කියන්නේ emitter current එකේ දිශාව. npn: B → E. pnp: E → B.
මතක තියාගන්න ලේසි ක්‍රමයක්: NPN = "Not Pointing iN". npn එකේ ඊතලය ඇතුළට යොමු වෙන්නේ නෑ, එළියට.

Currents තුනට නම්: IC (collector current), IB (base current), IE (emitter current). Kirchhoff current law එක transistor එක වටේට යොදලා බැලුවොත්, ඇතුළට යන ඒවායේ එකතුව එළියට එන එකට සමානයි. ඒක ඊළඟ කොටසේදී සූත්‍රයක් විදියට ලියනවා.

Bias දෙක: EBJ forward, CBJ reverse

Transistor එකක් amplifier එකක් විදියට වැඩ කරන්න නම් junctions දෙක bias කරන්න ඕනේ මෙහෙමයි:

  • Emitter-base junction (EBJ): forward bias. npn එකේ base (p) එක emitter (n) එකට වඩා ධන කරනවා (silicon වලට ~0.7 V).
  • Collector-base junction (CBJ): reverse bias. Collector (n) එක base (p) එකට වඩා ගොඩක් ධන කරනවා.

හිතන්න emitter එක කියන්නේ electrons පිරිලා තියෙන "ටැංකියක්" (doping ගොඩක් නිසා). EBJ forward bias කරාම ටැංකියේ දොර ඇරෙනවා. Electrons base එක දිහාට දුවනවා. මේ electrons ගලායාම තමයි emitter current IE එක හදන්නේ.

Electrons ගමන් කරන හැටි

Base එකට ආව electrons වලට එතන තියෙන holes එක්ක recombine (electron එකක් hole එකක් පුරවලා දෙකම නැතිවෙන එක) වෙන්න බලනවා. ඒත් base එක:

  • ගොඩක් සිහින්: electron එකකට base එක පනින්න යන්නේ පොඩි දුරක් විතරයි.
  • Doping අඩුයි: holes ගොඩක් නෑ, ඒ නිසා electron එකකට hole එකක් හම්බවෙන අවස්ථාව අඩුයි.

ඒ නිසා electrons වලින් ගොඩක් පොඩි ප්‍රමාණයක් (සාමාන්‍යයෙන් 1–2% වගේ) විතරයි base එකේ recombine වෙන්නේ. ඒ recombine වෙන electrons වෙනුවට base terminal එකෙන් අලුත් holes සපයන්න ඕනේ. ඒ පොඩි current එක තමයි base current IB.

ඉතුරු electrons (98–99%) base එක පැනලා CBJ එකට ළං වෙනවා. CBJ එක reverse bias නිසා ඒ junction එකේ ප්‍රබල electric field එකක් තියෙනවා. ඒක collector පැත්තට (ධන පැත්තට) electrons ඇදලා ගන්නවා, හරියට වතුර ඇල්ලකින් පහළට වැටෙනවා වගේ. මේ electrons තමයි collector current IC එක හදන්නේ.

මෙතන තියෙන මැජික් එක: පුංචි IB එක පොඩ්ඩක් වෙනස් කළොත් (EBJ එකේ voltage එක වෙනස් කරලා), ලොකු IC එක ඒ අනුපාතයෙන්ම ලොකුවට වෙනස් වෙනවා. Amplification එකේ මූලය මේකයි.

Current සම්බන්ධතාවය IE = IB + IC

Emitter එකෙන් පිටවෙන හැම electron එකක්ම එක්කෝ base එකේ නතර වෙනවා (IB), නැත්නම් collector එකට යනවා (IC). වෙන යන්න තැනක් නෑ. ඒ නිසා:

IE=IB+ICI_E = I_B + I_Cඕනෑම BJT එකකට, ඕනෑම mode එකක ඇත්ත. Transistor එක වටේට KCL.

Common base (CB)

Input signal එක emitter-base අතරට, output එක collector-base අතරින්. Base එක දෙකටම පොදුයි. Input current එක IE, output current එක IC. IC = αIE නිසා current gain එක α (1 ට අඩුයි). ඒත් input resistance එක ගොඩක් අඩුයි (~100 Ω) සහ output resistance එක ගොඩක් වැඩියි, ඒ නිසා voltage gain එකක් ලැබෙනවා. High frequency වලට හොඳයි.

Common emitter (CE)

Input එක base-emitter අතරට, output එක collector-emitter අතරින්. Emitter එක පොදුයි. Input current IB, output current IC නිසා current gain එක β (ලොකුයි). Voltage gain එකත් ලොකුයි. ඒ නිසා power gain එක තුනෙන්ම වැඩියි. Amplifiers වලින් ගොඩක් පාවිච්චි වෙන "workhorse" එක මේක. Output එක input එකට 180° කින් පෙරළිලා (inverted).

Common collector (CC)

Input එක base-collector අතරට, output එක emitter-collector අතරින් (collector එක supply එකට සම්බන්ධ නිසා ac වලට ground). Voltage gain එක 1 ට ටිකක් අඩුයි, output එක input එක "පස්සෙන් යනවා". ඒ නිසා emitter follower කියලත් කියනවා. Input resistance ගොඩක් වැඩියි, output resistance ගොඩක් අඩුයි, ඒ නිසා impedance matching (ලොකු resistance එකකින් එන signal එකක් අඩු resistance load එකකට ගැලපීම) වලට පාවිච්චි කරනවා.

05 · Transistor as an amplifier in CE · L02 slides 15–16

CE connection එක amplifier එකක් විදියට

Circuit එකේ කොටස් බලමු. Base loop එකේ ac signal source එකයි VBB battery එකයි series. Collector loop එකේ load resistor RC සහ VCC supply එක. Emitter එක දෙකටම පොදුයි.

VBB ඕනේ ඇයි? Signal එකේ negative half එකේදී base එකට −10 mV වගේ ආවොත්, VBB නැත්නම් EBJ එක reverse වෙලා transistor එක cut-off වෙනවා, signal එකෙන් භාගයක් නැතිවෙනවා. VBB එකෙන් EBJ එක input එකේ polarity එක මොකක් වුණත් forward bias එකේ තියාගන්නවා. ඒක තමයි biasing (signal එක එන්න කලින් transistor එක active mode එකේ මැදට ගෙනියන එක).

Positive half cycle එකේදී

Input එක ධන වෙද්දී VBB එකට තව voltage එකක් එකතු වෙනවා. EBJ එක තවත් forward bias වෙනවා. Emitter එකෙන් තවත් electrons විදිනවා, ඒ ලොකු current එක collector එක හරහා load එකට ගලනවා. පොඩි base current වෙනසකට ලොකු collector current වෙනසක්: මේක තමයි amplification එක.

Negative half cycle එකේදී සහ phase reversal

Input එක සෘණ වෙද්දී EBJ එකේ forward bias එක අඩු වෙනවා. Emitter එකෙන් අඩුවෙන් electrons යවනවා, IC අඩු වෙනවා.

දැන් output voltage එක බලන්න. Collector loop එකට KVL: vCE=VCC−iCRC\displaystyle v_{CE} = V_{CC} - i_C R_C. iC වැඩි වෙද්දී RC හරහා drop එක වැඩියි, ඒ නිසා vCE අඩු වෙනවා. iC අඩු වෙද්දී vCE වැඩි වෙනවා. ඒ කියන්නේ collector voltage එක input එකට විරුද්ධ දිශාවට යනවා: input එක උඩට යද්දී output එක පහළට. මේකට කියන්නේ 180° phase shift (output එක input එකේ උඩු යටිකුරු පිටපතක්) කියලා.

Common-emitter (CE) amplifier: circuit එක සහ DC analysis

Common-emitter (CE) amplifier එකේ input එක base එකට දෙනවා, output එක collector එකෙන් ගන්නවා. Common-collector (CC) amplifier: emitter follower

Common-collector (CC) amplifier එකට emitter follower (EF) කියලත් කියනවා. Collector එක VCC එකට කෙලින්ම සම්බන්ධ නිසා ac වලට ground. Input base එකට, output emitter එකෙන්. Emitter voltage එක හැම වෙලාවෙම base voltage එකට වඩා 0.7 V අඩුයි, ඒ නිසා base එක 1 V වෙනස් වුණොත් emitter එකත් ≈ 1 V වෙනස් වෙනවා: voltage gain ≈ 1, phase inversion නෑ.

Common-base (CB) amplifier එකේ base එක ac ground (C2 නිසා), input එක emitter එකට, output එක collector එකෙන්. ලක්ෂණ: voltage gain ලොකුයි, current gain උපරිම 1, input resistance ගොඩක් අඩුයි. Phase inversion නෑ: emitter එක පහළට ගියාම VBE වැඩි වෙලා IC වැඩි වෙනවා, ඒ නිසා VC පහළට යනවා. Emitter පහළ → collector පහළ: input සහ output එකම phase.

Differential amplifier (diff-amp)

Differential amplifier (inputs දෙකක වෙනස විතරක් amplify කරන amplifier එක) එකේ output එක inputs දෙකේ වෙනසේ function එකක්. Inputs දෙක සමාන නම් output එක 0. Op-amp එකක input stage එක diff-amp එකක්. Transistors දෙක හරියටම සමාන (matched) කියලා ගන්නවා: input signal එකක් නැති වෙලාවට dc emitter currents දෙක සමානයි.

Common-mode (inputs දෙකටම පොදු, එක සමාන signal එක) අවස්ථාවේ inputs දෙකට එකම signal එක එනවා. Input 1 නිසා out 1 එකේ inverted signal එකක්, input 2 නිසා out 1 එකේ non-inverted signal එකක්. ඒ දෙක සමාන සහ ප්‍රතිවිරුද්ධ නිසා අවලංගු වෙනවා. Output ≈ 0. Out 2 ටත් එහෙමමයි.

මේකේ ප්‍රායෝගික වටිනාකම: වයර් දිගේ එන noise (උදා: 50 Hz mains hum) inputs දෙකටම එකම විදියට පේනවා (common-mode). අපිට ඕනේ signal එක inputs දෙක අතර වෙනසක් විදියට එනවා (differential). Diff-amp එක desired signal එක amplify කරලා noise එක ඉවත් කරනවා. ECG, microphone, sensor amplifiers වල මේක අත්‍යවශ්‍යයි.
