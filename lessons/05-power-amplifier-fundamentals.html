Power amplifier කියන්නේ මොකක්ද?

Power amplifier (load එකට ලොකු power ප්‍රමාණයක් දෙන amplifier එක) එකක රස්සාව signal එකේ voltage එක විතරක් නෙවෙයි, current එකත් ලොකු කරලා, load එකට watts ගණනක් දෙන එක. Speaker එකක් හොඳට ශබ්ද කරන්න නම් volts ටිකක් මදි. ඒකට amps ගණනක් ගලන්නත් ඕනේ. Power = V × I නිසා, දෙකම ලොකු වෙන්න ඕනේ.

  • සාමාන්‍යයෙන් load එක අඩු resistance එකක් (current ලේසියෙන් ගලන, "බර" load එකක්). Audio speaker එකක් 8 Ω, transmission antenna එකක් 300 Ω වගේ.
  • සාමාන්‍ය power amplifier එකක output rating එක 1 W හෝ ඊට වැඩි.
  • Ideal (පරිපූර්ණ) power amp එකක් supply එකෙන් ගන්න power එකෙන් 100% ම load එකට දෙනවා. ඇත්ත ලෝකයේ එහෙම වෙන්නේ නෑ, මොකද circuit එකේ resistors, transistor වගේ හැම කොටසක්ම ටිකක් power dissipate (රස්නය විදියට නාස්ති) කරන නිසා.

⚠ සැලකිය යුතුයි: Slide 2 එකේ "load values range from 300W ... to 8W" කියලා තියෙනවා. ඒක font එකේ අවුලක්. Ω (ohm) අකුර W බවට හැරිලා. හරි එක: 300 Ω (antenna) සිට 8 Ω (speaker) දක්වා. ඒවා load එකේ resistance, power නෙවෙයි.

PWM driven (switching) classes

Slide 5 එකේ දෙවෙනි කාණ්ඩය PWM driven power amplifiers. මේවා digital circuits සහ PWM (Pulse Width Modulation: pulse එකේ පළල signal එක අනුව වෙනස් කරන ක්‍රමය) පාවිච්චි කරලා transistor එක "fully ON" සහ "fully OFF" අතරේ දිගටම switch කරනවා. Class B: transistor දෙකක්, භාගය බැගින්

Class B amplifier එකක operating point එක characteristic එකේ එක අන්තයක (cut-off එකේ) තියෙනවා. ඒ නිසා quiescent power (signal එක නැති වෙලාවේ ගන්න power එක) ගොඩක් පොඩියි. එක transistor එකකින් output එක ලැබෙන්නේ input cycle එකෙන් භාගයකට (180°) විතරයි.

වැඩ කරන හැටි: Vi අනුව අවස්ථා තුන

  • vI=0v_I = 0: QNQ_N සහ QPQ_P දෙකම cut off. vO=0v_O = 0. Supply එකෙන් current ගන්නේ නෑ.
  • vI>0.5v_I > 0.5 V: QNQ_N ON, QPQ_P cut off. QNQ_N emitter follower එකක්: vO=vI−VBENv_O = v_I - V_{BEN}. Current එක +VCC+V_{CC} → QNQ_N → RLR_L → ground.
  • vI<−0.5v_I < -0.5 V: QPQ_P ON, QNQ_N cut off. vO=vI+VEBPv_O = v_I + V_{EBP}. Current එක ground → RLR_L → QPQ_P → −VCC-V_{CC}.

Push-pull: එකෙක් තල්ලු කරනවා, අනිකා අදිනවා

Push-pull (තල්ලු කිරීම සහ ඇදීම) operation එකේ output devices දෙකක් load එක drive කරනවා:

  • එක device එකක් load එක හරහා එක දිශාවකට current එක යවනවා (pushing).
  • අනිත් device එක ප්‍රතිවිරුද්ධ දිශාවට current එක ගෙනියනවා (pulling).
  • සාමාන්‍යයෙන් devices දෙක class B transistors දෙකක්: එකක් input එක positive වෙද්දී විතරක්, අනික negative වෙද්දී විතරක් conduct කරනවා.

Slide 25 එකේ තවත් ආකාරයක් තියෙනවා: resistor biasing (R1,RB1,RB2,R2R_1, R_{B1}, R_{B2}, R_2) සහ input capacitors C1,C2C_1, C_2 එක්ක single-supply circuit එකක්. ඒක 13 වන කොටසේ විස්තරාත්මකව බලමු.

Even harmonics ගැන: transistor එකක් තනියම half-wave එකක් දෙද්දී ඒකේ ලොකු even harmonics (2f, 4f ... වගේ ඉරට්ටේ ගුණාකාර frequencies) තියෙනවා. Push-pull එකේ halves දෙක සමමිතික නිසා load එකේදී even harmonics එකිනෙක cancel වෙනවා. ඒ නිසා push-pull class B එකකින් transistor එකකට වැඩි output එකක්, අඩු distortion එකකින් ගන්න පුළුවන්.

⚠ සැලකිය යුතුයි: Slide 21 එකේ "Some amount of distortion in the circuit gives the more output per device because of there is no presence of the even harmonics" කියන වාක්‍යය පැටලිලා. හරි අදහස: push-pull සැකැස්ම even harmonics cancel කරන නිසා distortion අඩුයි, ඒ නිසා එක් device එකකින් වැඩි output power එකක් ගන්න පුළුවන්. Complementary symmetry transistors (ගුණාංග සමාන npn/pnp යුගලයක්) තියෙන push-pull amplifiers එක voltage source එකකින් වැඩ කරවන්න පුළුවන්. Class C amplifier එකක operating point එක තෝරලා තියෙන්නේ input sinusoid cycle එකෙන් භාගයකට වඩා වැඩි කාලයක් output current එක ශුන්‍ය වෙන විදියට. ඒ කියන්නේ conduction 180° ට අඩුයි. Base එකට negative bias (−VBB-V_{BB}) එකක් දාලා තියෙන නිසා input එකේ ඉහළම කොටසේදී විතරයි transistor එක ON වෙන්නේ.

Class G සහ H: class AB + smart supply

Classes G සහ H කියන්නේ මූලික class AB design එකේ දියුණු කිරීම්. අදහස: transistor එකේ නාස්තිය P=(Vrail−vo)×iP = (V_{rail} - v_o) \times i. Rail එක output එකට ළඟින් තිබ්බොත් නාස්තිය අඩුයි.

  • Class G: විවිධ voltages වල supply rails කිහිපයක් පාවිච්චි කරනවා. Supply voltage එක ඉහළට දාන්නේ ලොකුම signals තියෙද්දී විතරක් නිසා average power consumption එක, ඒ නිසා නාස්ති power එකෙන් හටගන්න රස්නය අඩුයි.

Class I: interleaved PWM

Class I amplifier එකේ complementary output switching devices කට්ටල දෙකක් parallel push-pull ආකාරයකට සකස් කරලා තියෙනවා. කට්ටල දෙකම එකම input waveform එක sample කරනවා. එක device එකක් waveform එකේ positive half එකත්, අනික negative half එකත් switch කරනවා (class B වගේ).

  • Input signal එකක් නැතිවිට, නැත්නම් signal එක zero-crossing point එකට ආවම, switching devices දෙකම 50% PWM duty cycle එකකින් එකවර ON/OFF වෙනවා. ඒකෙන් high frequency signals cancel වෙනවා.
  • Output signal එකේ positive half එක හදන්න positive switching device එකේ duty cycle එක වැඩි කරලා negative device එකේ duty cycle එක ඒ ප්‍රමාණයෙන්ම අඩු කරනවා. Negative half එකට අනිත් පැත්තට.
  • Switching signal currents දෙක output එකේදී interleaved (එකිනෙක අතරට පටලවලා) නිසා class I ට "interleaved PWM amplifier" කියනවා. Switching frequencies 250 kHz ට වැඩියි.

Class S සහ Class T

Class S power amplifier එකක් class D වගේම non-linear switching mode amplifier එකක්. ඒක analog input signals delta-sigma modulator (signal එක ඉතා වේගවත් 1/0 පෙළක් බවට හරවන circuit එකක්) එකකින් digital square wave pulses බවට හරවලා, output power එක වැඩි කරන්න amplify කරලා, අවසානයේ band pass filter (යම් frequency පරාසයක් විතරක් යවන filter එක) එකකින් demodulate කරනවා. Digital signal එක හැම වෙලාවෙම fully ON හෝ OFF නිසා (theory එකට අනුව dissipation ශුන්‍යයි) 100% දක්වා efficiencies ගන්න පුළුවන්.

Class T amplifiers දැන් audio amplifier design එකක් විදියට ජනප්‍රිය වෙමින් තියෙනවා. Class T designs class AB එකේ අඩු distortion සහ class D එකේ power efficiency දෙකම එකට ගන්නවා.
