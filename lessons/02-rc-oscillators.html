RC Phase Shift Oscillator: මූලික අදහස

ඕනෑම oscillator එකක් කියන්නේ amplifier (A) (signal එක ලොකු කරන කොටස) එකක් සහ feedback network (β) (output එකෙන් කොටසක් ආපහු input එකට යවන කොටස) එකක් loop එකකට සම්බන්ධ කරපු එකක්. කලින් පාඩමේ ඒක බැලුවා.

Loop එක වටේ phase එක 360° කරගන්න හැටි

RC phase shift oscillator එකේ amplifier එක inverting amplifier (output එක input එකේ උඩු යටිකුරු පිටපත) එකක්. ඒක signal එක 180° කරකවනවා. ඉතුරු 180° දෙන්නේ RC කොටස් වලින් හදපු β network එක. එතකොට loop එක වටේ මුළු phase එක:

∠Aβ = 180° (amplifier) + 180° (RC network) = 360° ≡ 0°

Barkhausen කොන්දේසි දෙක (Slide 2)

  1. Phase කොන්දේසිය: ∠Aβ = 0° හෝ 360°. ඒ කියන්නේ ආපහු එන signal එක input එකට එකතු වෙන්න ඕනේ (positive feedback).
  2. Magnitude කොන්දේසිය: |Aβ| = 1. ආපහු එන signal එක තියෙන එකට හරියටම සමාන ප්‍රමාණයක් වෙන්න ඕනේ.

RC network එක 180° දෙන්නේ එක frequency එකකදී විතරයි. ඒ frequency එක තමයි oscillator එකේ output frequency එක. වෙන frequencies වලට phase එක 360° වෙන්නේ නැති නිසා ඒවා loop එකේ ජීවත් වෙන්නේ නෑ. ඒ නිසා output එක එක frequency එකක පිරිසිදු sine wave එකක්.

මතක තියාගන්න: RC network එකෙන් frequency එක තීරණය වෙනවා (phase කොන්දේසිය). Amplifier gain එකෙන් wave එක ජීවත්ව තියෙනවා (magnitude කොන්දේසිය).

පුහුණු ප්‍රශ්න · 1

  1. RC phase shift oscillator එකේ inverting amplifier එකක් පාවිච්චි කරන්නේ ඇයි?
  2. Amplifier එක 180° දෙනවා නම්, β network එකෙන් කීයක් දෙන්න ඕනෙද? ඇයි?
  3. Phase කොන්දේසිය සපුරන්නේ එක frequency එකකදී විතරක් වීම හොඳ දෙයක් වෙන්නේ ඇයි?
පිළිතුර 1

Inverting amplifier එක ලේසියෙන්ම 180° phase shift එකක් දෙනවා. ඉතුරු 180° RC network එකෙන් දුන්නම මුළු loop phase එක 360° වෙනවා, Barkhausen phase කොන්දේසිය සපුරනවා.

පිළිතුර 2
  1. Loop එකට ඕනේ මුළු phase එක 360°.
  2. 360° − 180° = 180°.
පිළිතුර 3

ඒ නිසා loop එකේ ජීවත් වෙන්නේ එක frequency එකක් විතරයි. වෙන frequencies මැකිලා යනවා. ප්‍රතිඵලය එක frequency එකක පිරිසිදු sine wave එකක්. Phase කොන්දේසිය frequencies ගොඩකට සපුරනවා නම් output එක මිශ්‍ර, අවුල් wave එකක් වෙනවා.

එක RC stage එකක් කොච්චර phase එකක් දෙනවද?

Network එකේ මූලික කොටස මේ පුංචි circuit එක: series එකේ C, ඊට පස්සේ ground එකට R. Output එක ගන්නේ R එක හරහා. මේකට CR high-pass section (අඩු frequencies නවත්තලා වැඩි ඒවා යවන කොටස) කියනවා.

Transfer function එක ලියමු

මේක voltage divider (voltage එක කොටස් දෙකකට බෙදන circuit එක) එකක්. C එකේ impedance එක −jXc, R එකේ R.

  1. Vo / Vin = R / (R − jXc)
  2. Xc = 1/ωC දාන්න:
    Vo / Vin = R / (R − j/ωC)
  3. උඩයි යටයි R වලින් බෙදන්න:
    Vo / Vin = 1 / (1 − j/(ωCR))

Phase එක සහ gain එක

භාගයක phase එක = උඩ phase එක − යට phase එක. උඩ (1) phase එක 0. යට 1 − j/(ωCR) phase එක tan⁻¹(−1/ωCR).

φ = 0 − tan⁻¹(−1/ωCR) = tan⁻¹(1/ωCR) = tan⁻¹(Xc / R)

φ ධන (+) නිසා Vo එක Vin එකට වඩා ඉස්සරහින් යනවා. මේකට phase lead (output එක input එකට කලින් peak එකට එන එක) කියනවා. Slide එකේ නැති, ඒත් ගොඩක් වැදගත් දෙවෙනි කොටස මේක:

|Vo / Vin| = R / √(R² + Xc²) = cos φ
  • අඩු frequency: Xc ලොකුයි → φ 90° ට කිට්ටුයි, ඒත් output එක ගොඩක් පුංචියි.
  • වැඩි frequency: Xc පුංචියි → φ 0° ට කිට්ටුයි, output ≈ input.
  • φ කවදාවත් 90° ට වඩා වැඩි වෙන්නේ නෑ. ඒක හරියටම 90° වෙන්නේ f = 0 දී විතරයි, එතකොට output එක බිංදුව.

    Vin = Vo [1 + 6/(jωCR) − 5/(ω²C²R²) − 1/(jω³C³R³)]

පියවර 6: Imaginary කොටස = 0 → frequency (Slide 19)

Phase එක හරියටම 180° වෙන්න Vin/Vo සම්පූර්ණයෙන්ම real (සෘණ) අගයක් වෙන්න ඕනේ. ඒ කියන්නේ j තියෙන පද එකතුව බිංදුව වෙන්න ඕනේ.

  1. j තියෙන පද දෙක: 6/(jωCR) සහ −1/(jω³C³R³). 1/j පොදුයි, ඒක අයින් කරන්න:
    6/(ωCR) − 1/(ω³C³R³) = 0
  2. ω³C³R³ වලින් ගුණ කරන්න:
    6 ω²C²R² − 1 = 0  →  ω²C²R² = 1/6
  3. ω = 1/(√6 · RC)
  4. ω = 2πf නිසා:
    f = 1 / (2π RC √6)

පියවර 7: Real කොටස → β = −1/29 (Slide 21)

  1. Imaginary කොටස අයින් වුණාම ඉතුරු:
    Vin = Vo [1 − 5/(ω²C²R²)]
  2. ω²C²R² = 1/6 නිසා 1/(ω²C²R²) = 6:
    Vin = Vo [1 − 5 × 6] = Vo [1 − 30] = −29 Vo
  3. β = Vo / Vin = −1/29

− ලකුණ = 180° phase shift එක. 1/29 = network එක signal එක 29 ගුණයකින් අඩු කරනවා. ඉතින් amplifier එකට |A| ≥ 29 ඕනේ.

පුහුණු ප්‍රශ්න · 5

  1. 1/j = −j බව පෙන්වන්න. ඒ නිසා −jXc = 1/(jωC) බව පෙන්වන්න.
  2. a = 1/(jωCR) කියලා ගත්තම, ω = 1/(√6 RC) දී a² සහ a³ අගයන් හොයලා 1 + 6a + 5a² + a³ = −29 බව පෙන්වන්න.
  3. R සහ C දෙකම දෙගුණ කළොත් f සහ β අගයන් වලට මොකද වෙන්නේ?
පිළිතුර 1
  1. 1/j = j/(j·j) = j/(−1) = −j
  2. −jXc = −j · 1/(ωC) = (1/j)·(1/ωC) = 1/(jωC)
පිළිතුර 2
  1. ωCR = 1/√6 නිසා a = √6/j = −j√6
  2. a² = (−j√6)² = j²·6 = −6
  3. a³ = a²·a = (−6)(−j√6) = 6j√6
  4. 6a = −6j√6
  5. 1 + 6a + 5a² + a³ = 1 − 6j√6 − 30 + 6j√6 = −29. j කොටස් කැපිලා යනවා, ඒක තමයි 180° වෙන හේතුව.
පිළිතුර 3
  1. RC 4 ගුණයක් වෙනවා (2 × 2). f = 1/(2πRC√6) නිසා f, 4න් පංගුවක් වෙනවා.
  2. β = −1/29 RC මත රඳා පවතින්නේ නෑ (ωRC = 1/√6 පමණක් වැදගත්). ඒ නිසා β වෙනස් වෙන්නේ නෑ, ඕනේ gain එකත් 29 ම යි.

Wien Bridge Oscillator: circuit එක

දෙවෙනි RC oscillator එක මේක. මෙතන අදහස වෙනස්: amplifier එක non-inverting amplifier (output එක input එකේ දිශාවටම, උඩු යටිකුරු නොකර) එකක්. ඒක phase එක 0° යි. ඉතින් feedback network එකත් 0° දෙන්න ඕනේ:

∠Aβ = 0° (amplifier) + 0° (lead-lag network) = 0°

Bridge එකක් විදියට (Slide 20)

Circuit එකේ කොටස් හතර (arms) bridge (diamond හැඩයට සම්බන්ධ කරපු arms හතරක්) එකක් හදනවා. Op-amp එකේ inputs දෙක bridge එකේ මැද points දෙකට සම්බන්ධයි.

සාමාන්‍ය op-amp ආකාරයට (Slide 22)

Circuit එකේ කොටස් දෙකක් තියෙනවා:

  • Lead-lag network (R1, C1, R2, C2): Vout එකෙන් කොටසක් + input එකට යවනවා. මේකෙන් frequency එක තීරණය වෙනවා.
  • R3, R4: negative feedback එකෙන් amplifier gain එක A = 1 + R4/R3 කරනවා. මේකෙන් gain කොන්දේසිය සපුරනවා.

⚠ සැලකිය යුතුයි (නම): Slides වල හැම තැනම "Wein Bridge" කියලා තියෙනවා. හරි නම Wien Bridge (Max Wien කියන විද්‍යාඥයාගේ නමින්). Exam එකේ "Wien" කියලා ලියන්න.

⚠ සැලකිය යුතුයි (R3/R4 ලේබල්): Slide 20 එකේ R3 තියෙන්නේ Vout සහ − input අතර (feedback resistor), R4 − input සහ ground අතර. Slide 22 එකේ ඒ දෙක මාරු වෙලා: R4 feedback, R3 ground. Slides 32–33 එකේ A = 1 + R4/R3 සූත්‍රය හරි යන්නේ Slide 22 labelling එකට. Slide 20 labels පාවිච්චි කළොත් A = 1 + R3/R4 සහ R3/R4 = 2 වෙනවා. සරලවම මතක තියාගන්න: feedback resistor = ground resistor × 2.

පුහුණු ප්‍රශ්න · 6

  1. Wien bridge oscillator එකේ non-inverting amplifier එකක් පාවිච්චි කරන්නේ ඇයි?
  2. Op-amp එකේ + input සහ − input වලට සම්බන්ධ වෙන්නේ මොන කොටස් වලටද?
පිළිතුර 1

Lead-lag network එක oscillation frequency එකේදී 0° phase shift එකක් දෙනවා. Loop එකේ මුළු phase එක 0° (හෝ 360°) වෙන්න amplifier එකත් 0° දෙන්න ඕනේ. Non-inverting amplifier එක 0° දෙනවා. (Inverting එකක් දැම්මොත් loop එක 180° වෙලා negative feedback වෙනවා.)

පිළිතුර 2
  • + input: lead-lag network එකේ මැද node එක (R1C1 සහ R2∥C2 හමුවෙන තැන). මේක positive feedback.
  • − input: R3, R4 voltage divider එකේ මැද. මේක negative feedback, gain එක පාලනය කරනවා.

Lead-lag network: HPF + LPF = band-pass

Feedback network එක වෙනම ගත්තම (Slide 23) series R1-C1 එකක් සහ parallel R2∥C2 එකක් තියෙන voltage divider එකක්.

අඩු frequency වලදී

C1 එකේ Xc ගොඩක් ලොකුයි, ඒක open circuit එකක් වගේ. Signal එක ඉස්සරහට යන්නේ නෑ → Vout ≈ 0. Phase එක +90° ට කිට්ටුයි (lead). මේ නිසා උඩ කොටසට HPF (high-pass filter: වැඩි frequencies යවන) කියනවා.

වැඩි frequency වලදී

C2 එකේ Xc ගොඩක් පුංචියි, ඒක Vout එක ground එකට short කරනවා → Vout ≈ 0. Phase එක −90° ට කිට්ටුයි (lag). මේ නිසා යට කොටසට LPF (low-pass filter: අඩු frequencies යවන) කියනවා.

මැද frequency එකේදී: fr

දෙපැත්තෙන්ම අඩු වෙන නිසා මැද තැනක output එක උපරිම. ඒකට resonant frequency (fr) (network එක වැඩිපුරම signal එක යවන, phase එක බිංදුව වෙන frequency එක) කියනවා. මේ network එක band-pass filter (එක frequency පරාසයක් විතරක් යවන) එකක්. Lead සහ lag දෙකම තියෙන නිසා නම lead-lag network.

Slides වල "LPF" කියන්නේ R2∥C2 කොටස divider එකේ යට arm එක විදියට වැඩ කරන එකට. ඒක තනියම filter එකක් නෙවෙයි; Z1 එක්ක එකතු වුණාම තමයි filter හැසිරීම එන්නේ.

Wien: fr සහ β = 1/3 derivation

සාමාන්‍ය අවස්ථාව (R1, R2, C1, C2 වෙනස් අගයන්) සඳහා derive කරලා, අන්තිමට R1 = R2 = R, C1 = C2 = C දාමු.

පියවර 1: Z1 සහ Z2

  1. Series කොටස:
    Z1 = R1 + 1/(jωC1)
  2. Parallel කොටස (product / sum):
    Z2 = R2 ∥ 1/(jωC2) = [R2 · 1/(jωC2)] / [R2 + 1/(jωC2)] = R2 / (1 + jωR2C2)

පියවර 2: Voltage divider (Slide 29)

  1. Vo/Vin = Z2 / (Z1 + Z2)
  2. උඩයි යටයි (1 + jωR2C2)·jωC1 වලින් ගුණ කරන්න:
    Vo/Vin = jωR2C1 / [ jωR1C1(1 + jωR2C2) + (1 + jωR2C2) + jωR2C1 ]
  3. යට කොටස expand කරලා real සහ imaginary වෙන් කරන්න (Slide 30):
    Vo/Vin = jωR2C1 / [ (1 − ω²R1R2C1C2) + jω(R1C1 + R2C2 + R2C1) ]

පියවර 3: Phase = 0 → fr

උඩ කොටස (jωR2C1) සම්පූර්ණයෙන්ම imaginary. භාගයේ phase එක 0 වෙන්න යට කොටසත් සම්පූර්ණයෙන්ම imaginary වෙන්න ඕනේ. ඒ කියන්නේ යට real කොටස = 0:

  1. 1 − ω²R1R2C1C2 = 0  →  ω² R1R2C1C2 = 1
  2. ω = 1 / √(R1R2C1C2)
  3. fr = 1 / (2π √(R1R2C1C2))
  4. R1 = R2 = R, C1 = C2 = C නම්:
    fr = 1 / (2π RC)

පියවර 4: fr දී β (Slide 31)

  1. Real කොටස අයින් වුණාම jω කැපිලා යනවා:
    β = Vo/Vin = R2C1 / (R1C1 + R2C2 + R2C1)
  2. R, C සමාන නම්:
    β = RC / (RC + RC + RC) = RC / 3RC
  3. β = 1/3  (phase 0°)

RC phase shift එකේ β = −1/29 එක්ක සසඳන්න. Wien network එක signal එක 3 ගුණයකින් විතරයි අඩු කරන්නේ, ඒ නිසා ඕනේ gain එකත් පුංචියි.

  1. R1 = R2 = 10 kΩ, C1 = C2 = 16 nF. fr සහ fr දී β හොයන්න.

  3. Z2 = R2/(1 + jωR2C2) බව පියවරෙන් පියවර පෙන්වන්න.

  3. සමාන අගයන් නිසා β = 1/3, phase 0°.

  1. R1R2C1C2 = 10k × 20k × 10n × 10n = 2×10⁸ × 1×10⁻¹⁶ = 2×10⁻⁸

  1. Parallel = product / sum: Z2 = [R2 · (1/jωC2)] / [R2 + 1/jωC2]

  3. Z2 = R2 / (1 + jωR2C2)

Wien: gain = 3, ඒ නිසා R4 = 2R3

  1. Barkhausen: Aβ = 1 → A = 1/β
  2. සාමාන්‍ය අවස්ථාවට:
    A = (R1C1 + R2C2 + R2C1) / R2C1 = R1/R2 + C2/C1 + 1
  3. Non-inverting amplifier gain එක A = 1 + R4/R3. සමාන කරන්න:
    1 + R4/R3 = 1 + R1/R2 + C2/C1  →  R4/R3 = R1/R2 + C2/C1
  4. R1 = R2, C1 = C2 නම්:
    R4/R3 = 1 + 1 = 2  →  A = 3
  • R4/R3 < 2 (A < 3): Aβ < 1, oscillation මැකිලා යනවා.
  • R4/R3 = 2 (A = 3): Aβ = 1, එකම amplitude එකෙන් දිගටම.
  • R4/R3 > 2 (A > 3): Aβ > 1, ලොකු වෙලා ±Vsat වලට වැදිලා clip වෙනවා (sine එක කැත වෙනවා).

ප්‍රායෝගිකව පටන් ගන්න R4/R3 ටිකක් 2 ට වැඩියෙන් තියලා, amplitude එක ලොකු වෙද්දී gain එක ආපහු 3 ට අඩු කරන ක්‍රමයක් පාවිච්චි කරනවා.
