01 · Feedback Introduction · පිටුව 1

Basic feedback structure

කොටස් හතර සහ signals

මුලින්ම රූපයේ තියෙන හැම නමක්ම තේරුම් ගමු.

  • xs: source signal (අපි දෙන input එක).
  • xf: feedback signal (output එකෙන් ආපහු එන කොටස).
  • xi: amplifier එකට ඇත්තටම යන signal එක. මේකට error signal (input එකයි ආපහු ආව එකයි අතර වෙනස) කියලත් කියනවා.
  • xo: output signal එක.

මේ signals voltage හෝ current වෙන්න පුළුවන්. හැබැයි එක නීතියක් තියෙනවා: xs, xf, xi තුනම එකම වර්ගයේ වෙන්න ඕනේ (තුනම voltage, නැත්නම් තුනම current). හේතුව සරලයි. Voltage එකකින් current එකක් අඩු කරන්න බෑ, අඹ වලින් දොඩම් අඩු කරන්න බැරි වගේ. xo නම් voltage හෝ current ඕනෑම එකක් වෙන්න පුළුවන්.

A සහ β

A කියන්නේ open-loop amplifier (feedback නැතුව තනියම තියෙන amplifier එක). ඒක xi අරගෙන A ගුණයක් කරනවා:

xo=A xi(1)x_o = A\,x_i \qquad (1)

β (beta) කියන්නේ feedback factor (output එකෙන් කොච්චර කොටසක් ආපහු යවනවද කියන අගය). සාමාන්‍යයෙන් β network එක resistors වගේ passive (තමන්ගේම power එකක් නැති, signal එක වැඩි කරන්න බැරි) කොටස් වලින් හදන නිසා β≤1\beta \le 1.

xf=β xo(2)x_f = \beta\,x_o \qquad (2)

Σ එකේදී අඩු කිරීම වෙනවා:

xi=xs−xf(3)x_i = x_s - x_f \qquad (3)

⚠ සැලකිය යුතුයි: Notes වල "passive network නිසා β ≤ 1" කියලා තියෙනවා. ඒක හරි යන්නේ xf සහ xo එකම වර්ගය නම් විතරයි (උදා: voltage / voltage). xo voltage එකක් සහ xf current එකක් නම් (shunt-shunt, කොටස 10), β ට units තියෙනවා (A/V, ඒ කියන්නේ 1/Ω). එතකොට "β ≤ 1" කියන එකට තේරුමක් නෑ. හැබැයි AβA\beta නම් හැම වෙලාවෙම units නැති අංකයක්.

Closed-loop gain සහ loop gain

Closed-loop gain සූත්‍රය හදමු

Closed-loop gain (feedback එකත් එක්ක මුළු circuit එකේ gain එක) අර්ථ දක්වන්නේ Af≡xo/xsA_f \equiv x_o / x_s කියලා. සමීකරණ (1), (2), (3) එකට දාමු:

  1. (3) එක (1) ට දාන්න:
    xo=A (xs−xf)x_o = A\,(x_s - x_f)
  2. (2) එකෙන් xf=βxox_f = \beta x_o දාන්න:
    xo=A xs−Aβ xox_o = A\,x_s - A\beta\,x_o
  3. xo තියෙන පද එක පැත්තකට:
    xo (1+Aβ)=A xsx_o\,(1 + A\beta) = A\,x_s
  4. දෙපැත්තම xs(1 + Aβ) න් බෙදන්න:
    Af=xoxs=A1+Aβ(4)A_f = \frac{x_o}{x_s} = \frac{A}{1 + A\beta} \qquad (4)

Negative feedback නිසා පහළ කොටස 1+Aβ1 + A\beta. ඒක 1 ට වඩා ලොකුයි. ඒ නිසා Af හැම වෙලාවෙම A ට වඩා අඩුයි. අපි gain ටිකක් "වියදම් කරනවා". ඒ වෙනුවට ලැබෙන දේවල් තමයි ඊළඟ කොටස් වල තියෙන්නේ.

Loop gain (L)

AβA\beta ට කියන්නේ loop gain (signal එකක් loop එක වටේ එක වටයක් ගියාම කී ගුණයක් වෙනවද). ඒකට L කියන නම දෙනවා:

L≡AβL \equiv A\beta

L ට units නෑ (dimensionless: නිකම්ම අංකයක්). A ගෙ units සහ β ගෙ units එකිනෙක කපාගෙන යනවා (උදා: A = V/A නම් β = A/V, ගුණ කළාම units නෑ).

Loop gain ගොඩක් ලොකු වුණාම

(4) හි උඩ සහ යට දෙකම AβA\beta න් බෙදුවොත්:

Af=A1+Aβ=1/β1+1AβAβ→∞  ⇒  Af→1βA_f = \frac{A}{1 + A\beta} = \frac{1/\beta}{1 + \dfrac{1}{A\beta}} \qquad A\beta \to \infty \;\Rightarrow\; A_f \to \frac{1}{\beta}

මේක තමයි negative feedback වල රහස. Closed-loop gain එක A මත රඳා පවතින්නේ නෑ, β මත විතරයි: Af≈1/βA_f \approx 1/\beta. β හදන්නේ resistors වගේ passive කොටස් වලින්. Resistors වල අගය නිවැරදිව (උදා: 0.1% tolerance) ගන්න පුළුවන්, උෂ්ණත්වයත් එක්ක එච්චර වෙනස් වෙන්නෙත් නෑ. Transistor එකක A නම් කෑල්ලෙන් කෑල්ලට, උෂ්ණත්වයෙන් උෂ්ණත්වයට ලොකුවට වෙනස් වෙනවා. ඉතින් නිවැරදි (accurate) gain එකක් ගන්න පුළුවන්.

Distortion reduction

Distortion කියන්නේ මොකක්ද?

Linear amp (හැම input අගයකටම එකම gain එක තියෙන amplifier) එකක vo සහ vi අතර graph එක සරල රේඛාවක්. Slope එක k. Sine wave එකක් දැම්මොත් එළියට එන්නෙත් ලොකු කරපු sine wave එකක්මයි.

ඇත්ත amplifier එකක නම් slope එක (gain එක) input එක අනුව වෙනස් වෙනවා. ඒක ±Vmax වලදී saturate (output එකට තවත් ඉහළ යන්න බැරිව සීමාවේ හිර වීම) වෙනවා. ඒ ළඟට යද්දි gain එක අඩු වෙනවා. Gain එක වෙනස් වීම නිසා තමයි non-linear distortion (output wave එකේ හැඩය වෙනස් වීම) එන්නේ. Negative feedback gain වෙනස් වීම අඩු කරනවා (කොටස 4) නිසා distortion එකත් අඩු වෙනවා.

Source follower push-pull සහ deadband

Negative feedback check ක්‍රමය

Circuit එකක feedback එක negative ද කියලා බලන සරල ක්‍රමයක්: input එක ටිකක් වැඩි කළා (↑) කියලා හිතලා, ඒ වෙනස loop එක වටේ පියවරෙන් පියවර යවන්න. අන්තිමට ආපහු ආව වෙනස මුල් vi වෙනසට විරුද්ධ නම් feedback එක negative.

  • vs↑⇒vi↑v_s\uparrow \Rightarrow v_i\uparrow
  • vi↑⇒vo↑v_i\uparrow \Rightarrow v_o\uparrow (+ input එකට වැඩි වුණා)
  • vo↑⇒vf↑v_o\uparrow \Rightarrow v_f\uparrow (divider එක)
  • vf↑⇒vi↓v_f\uparrow \Rightarrow v_i\downarrow ✓ මුල් vi වෙනසට විරුද්ධයි, ඒ නිසා negative feedback.

Common-gate series-shunt (ලකුණු මාරුයි)

  • vs↑⇒vi↓v_s\uparrow \Rightarrow v_i\downarrow (source voltage ↑ නිසා vGS ↓)
  • vi↓⇒vo↑v_i\downarrow \Rightarrow v_o\uparrow (current ↓, RD drop ↓)
  • vo↑⇒vf↑v_o\uparrow \Rightarrow v_f\uparrow
  • vf↑⇒vi↑v_f\uparrow \Rightarrow v_i\uparrow ✓ මුල් vi වෙනසට (↓) විරුද්ධයි: negative feedback.

Inverting op-amp: Norton වලට හරවන්න ඕනේ

Inverting amplifier එකේ input එක voltage source එකක් (vs) සහ R1. Shunt input එකක් කියන්නේ currents අඩු කරන එකක් නිසා, ඒක "needs modification". vs සහ R1 Norton equivalent (voltage source + series R → current source + parallel R) එකට හරවනවා:

is=vsR1,R1 දැන් node එකේ සිට ground එකටi_s = \frac{v_s}{R_1}, \qquad R_1 \text{ දැන් node එකේ සිට ground එකට}

Shunt-series: current buffer

Input පැත්තේ is current එක ඉහළ transistor එකේ source node එකට එනවා. ඒ node එකේදීම feedback current if (transistor එක හරහා යන current එක) අඩු වෙනවා: ii=is−ifi_i = i_s - i_f. ඉතින් input shunt. Output එක RL හරහා යන current io. ඒ current එකම transistor එක හරහා ගිහින් feedback වෙනවා, ඒ නිසා output series. Op-amp එක source node එකේ voltage එක VB2 ට සමානව තියාගන්නවා. පහළ transistor එක (VB1) bias current source එකක් විතරයි.

Notes වල check එක නෑ. මෙන්න (රූපයේ if ඉහළට, ඒ කියන්නේ if=−ioi_f = -i_o):

Loop gain (return ratio) ක්‍රමය

ඒ නිසා මේ පාඨමාලාව textbook එකෙන් වෙනස් වෙලා loop gain analysis ක්‍රමය පාවිච්චි කරනවා. ඒක තියෙන්නේ Analysis and Design of Analog Integrated Circuits, 5th edition, Gray / Hurst / Lewis / Meyer (2009) පොතේ.

  • Return-ratio ක්‍රමයේ loop gain එක වෙනස් වෙන්නේ නෑ. Input එක කොතනින් දැම්මත්, output එක කොතනින් ගත්තත් loop එක එකමයි, ඒ නිසා L එකමයි.
  • Loop gain එක තමයි circuit එකක stability (oscillate නොවී ස්ථාවරව තියෙනවද කියන එක) තීරණය කරන්නේ.

කොටස 10 හි "loop එක v1 දී කඩන" ක්‍රමය මේකමයි. ලකුණ (↑/↓) වෙනුවට අගයන් ගණන් කළොත් loop gain එක ලැබෙනවා:

L=−vrvt(xs=0)L = -\frac{v_r}{v_t} \qquad (x_s = 0)

Negative feedback එකක vrv_r ලකුණ vtv_t ට විරුද්ධ නිසා L ධන අංකයක්. (මේ සූත්‍රය notes වල කෙලින්ම නෑ, Gray පොතේ return ratio අර්ථ දැක්වීම.)
