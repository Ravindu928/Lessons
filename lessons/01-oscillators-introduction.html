Oscillator කියන්නේ මොකක්ද?

Oscillator (දිගටම පැද්දෙන signal එකක් හදන circuit එක) එකක් කියන්නේ, input එකට කිසිම AC signal එකක් දෙන්නේ නැතුව, output එකේ දිගටම උඩට පහළට යන wave එකක් දෙන circuit එකක්.

ඒකට දෙන්න ඕනේ DC power supply එකක් විතරයි (බැටරියක් වගේ, එක දිශාවට විතරක් යන current එකක්). Circuit එක ඒ DC energy එක අරගෙන ඒක AC output (දිශාව මාරු වෙවී යන signal එකක්) බවට හරවනවා.

Amplifier එකයි Oscillator එකයි අතර වෙනස

Amplifier (signal එක ලොකු කරන කොටස) එකකට input signal එකක් දුන්නොත් තමයි output එකක් එන්නේ. Input එක නැත්නම් output එකත් නෑ. Oscillator එකට input signal එකක් ඕනේ නෑ. ඒක තමන්ගේම output එකෙන් කොටසක් ආපහු input එකට දාගෙන දිගටම වැඩ කරනවා (මේක ඊළඟ කොටසින් බලමු).

Frequency කියන්නේ

Oscillator = Positive feedback තියෙන Amplifier එකක්

Oscillator එකක ඇතුලත ප්‍රධාන කොටස් තුනයි. Slide 2 රූපයේ ඒවා තියෙනවා:

  • A (gain: signal එක කී ගුණයකින් ලොකු කරනවද). උදා: A = 50 නම් 1 mV දුන්නොත් 50 mV එනවා.
  • β (beta) (feedback network: output එකෙන් කොටසක් අරන් ආපහු යවන කොටස). සාමාන්‍යයෙන් β එක 1ට අඩුයි. β = Vf / Vout. උදා: β = 0.02 නම් output එකෙන් 2% ක් ආපහු යනවා.
  • Σ (summing point) (signals දෙකක් එකතු කරන තැන). ලකුණු දෙකම + නිසා ආපහු එන කොටස input එකට එකතු වෙනවා.

එදිනෙදා උදාහරණයක්: Mic එක speaker එක ළඟට ගියාම

Function එකකදී mic එක speaker එක ළඟට ගෙනිච්චම "කීඊඊඊ" කියලා සද්දයක් එනවා නේද? ඒක හරියටම positive feedback oscillation එකක්. Mic එකට එන පුංචි සද්දය amplifier එකෙන් ලොකු වෙනවා, speaker එකෙන් එළියට එනවා, ඒක ආයේ mic එකට යනවා, ආයේ ලොකු වෙනවා... Input එකක් කවුරුත් දුන්නේ නැතත් සද්දයක් හැදෙනවා.

Feedback සහිත gain සූත්‍රය: A / (1 − Aβ)

දැන් loop එක වටේ voltage මොනවද කියලා පියවරෙන් පියවර ලියමු. මේක තමයි මුළු පාඩමේම වැදගත්ම derivation එක.

  1. β network එකෙන් output එකෙන් කොටසක් ආපහු එනවා:
    Vf = β · Vout
  2. Σ එකේදී Vin සහ Vf එකතු වෙනවා. Amplifier එකට යන්නේ මේ එකතුව:
    Amplifier input = Vin + Vf
  3. Amplifier එක ඒක A වලින් ගුණ කරනවා:
    Vout = A (Vin + Vf) = A·Vin + Aβ·Vout
  4. Vout තියෙන පද එක පැත්තකට ගන්න:
    Vout − Aβ·Vout = A·Vin
    Vout (1 − Aβ) = A·Vin
  5. එතකොට closed-loop gain (feedback එකත් එක්ක මුළු circuit එකේ gain එක):
    Af = Vout / Vin = A / (1 − Aβ)

Aβ ට කියන්නේ loop gain (signal එක loop එක වටේ එක වතාවක් ගියාම කී ගුණයක් වෙනවද). දැන් බලන්න, Aβ = 1 වුණොත් පහළ කොටස 1 − 1 = 0. බිංදුවෙන් බෙදුවම උත්තරය අනන්තයි (∞).

  2. |β| = 1 / 29 ≈ 0.0345

Input එකක් නැතුව oscillation එක පටන් ගන්නේ කොහොමද?

Oscillator එකේ Vin ≈ 0. එහෙනම් පළමු signal එක එන්නේ කොහෙන්ද? උත්තරය thermal noise (resistors ඇතුලේ electrons රස්නය නිසා අහඹු ලෙස සෙලවීමෙන් හැදෙන ඉතා පුංචි voltage එක, µV වගේ).

  1. Switch on කරනවා. Circuit එකේ resistors වල thermal noise එකක් හැදෙනවා. මේ noise එකේ හැම frequency එකක්ම ටික ටික තියෙනවා.
  2. β network එක පෙරනයක් (filter) වගේ. ඒක frequency selective (එක frequency එකකට විතරක් හරි phase එක දෙන). Barkhausen කොන්දේසි සපුරන්නේ f₀ ට විතරයි.
  3. f₀ ලොකු වෙනවා, අනිත් ඒවා මැකෙනවා. f₀ හැර අනිත් frequencies වල phase එක වැරදියි හෝ |Aβ| < 1. ඒවා මැකිලා යනවා. f₀ එක විතරක් වටෙන් වට ලොකු වෙනවා.
  4. ස්ථාවර වෙනවා. Amplitude එක ලොකු වෙද්දී amplifier gain එක ටිකක් අඩු වෙලා |Aβ| = 1 වෙනවා. එතකොට පිරිසිදු sine wave එකක් එකම ප්‍රමාණයෙන්.

• ස්ථාවර වුණාට පස්සේ |Aβ| = 1 වෙන්න ඕනේ. Amplifier එකේ non-linearity (ලොකු signals වලදී gain එක තනියම අඩු වෙන ගතිය) හෝ AGC circuit එකකින් මේක තනියම වෙනවා.
