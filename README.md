# ECD පාඩම් (Electronic Circuit Design)

Lecture slides වලින් හදපු සිංහල පාඩම් ටික. `index.html` කියන්නේ මුල් පිටුව. ඒකේ ඉඳන් හැම පාඩමකටම link තියෙනවා, හැම පාඩමකම පල්ලෙහා වම් පැත්තේ "← සියලු පාඩම්" button එකෙන් ආපහු මුල් පිටුවට එන්න පුළුවන්.

## Folder එක

```
index.html        මුල් පිටුව (පාඩම් ලැයිස්තුව)
lessons/          පාඩම් HTML files 4
README.md         මේ file එක
.nojekyll         GitHub Pages එකට files වෙනස් නොකර දාන්න කියන සලකුණ
```

## Computer එකේ open කරන හැටි

1. මුළු folder එකම download කරලා එක තැනක තියන්න (`lessons/` folder එක `index.html` එක ළඟම තියෙන්න ඕනේ).
2. `index.html` double-click කරන්න. Browser එකේ open වෙයි.
3. Fonts සහ සූත්‍ර හරියට පේන්න internet තියෙන්න ඕනේ (Google Fonts load වෙන්නේ online).

## GitHub Pages එකේ host කරන හැටි

1. GitHub එකේ අලුත් repository එකක් හදන්න (උදා: `ecd-lessons`).
2. මේ folder එකේ තියෙන දේවල් ඔක්කොම repository එකේ root එකට upload කරන්න (`index.html` root එකේම තියෙන්න ඕනේ).
3. Repository එකේ **Settings → Pages** යන්න. **Source** එක "Deploy from a branch" කරලා, branch එක `main` සහ folder එක `/ (root)` තෝරලා **Save** කරන්න.
4. විනාඩියක් දෙකක් ඉඳලා `https://<ඔයාගේ-username>.github.io/ecd-lessons/` open කරන්න.

## සටහන්

- Tick කරපු ප්‍රගතිය save වෙන්නේ browser එකේ (localStorage). ඒ නිසා computer එකේ file එකෙන් open කරපු එකයි GitHub Pages link එකයි අතර progress එක share වෙන්නේ නැහැ.
- අලුත් පාඩමක් එකතු කරනකොට HTML file එක `lessons/` එකට දාලා, `index.html` එකේ card එකක් එකතු කරන්න.
