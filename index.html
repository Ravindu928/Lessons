Oscillator කියන්නේ මොකක්ද?

Oscillator (දිගටම පැද්දෙන signal එකක් හදන circuit එක) එකක් කියන්නේ, input එකට කිසිම AC signal එකක් දෙන්නේ නැතුව, output එකේ දිගටම උඩට පහළට යන wave එකක් දෙන circuit එකක්.

ඒකට දෙන්න ඕනේ DC power supply එකක් විතරයි (බැටරියක් වගේ, එක දිශාවට විතරක් යන current එකක්). Circuit එක ඒ DC energy එක අරගෙන ඒක AC output (දිශාව මාරු වෙවී යන signal එකක්) බවට හරවනවා.

Amplifier (signal එක ලොකු කරන කොටස) එකකට input signal එකක් දුන්නොත් තමයි output එකක් එන්නේ. Input එක නැත්නම් output එකත් නෑ. Oscillator එකට input signal එකක් ඕනේ නෑ. ඒක තමන්ගේම output එකෙන් කොටසක් ආපහු input එකට දාගෙන දිගටම වැඩ කරනවා (මේක ඊළඟ කොටසින් බලමු).

LC Oscillator: මූලික අදහස සහ LC tank circuit එක

RC oscillators (8–17 කොටස්) වල β network එක හැදුවේ resistors සහ capacitors වලින්. LC oscillator එකේ block diagram එක හරියටම එකමයි: amplifier (A) එකක් සහ feedback network (β) එකක්. වෙනස එකයි, β කොටස දැන් inductor (L) (වයර් දඟරයක්, current එක වෙනස් වෙන එකට විරුද්ධ වෙන component එක) සහ capacitor (C) වලින් හදපු LC circuit එකක් (slide 1).

RC oscillators හොඳට වැඩ කරන්නේ Hz සිට සිය ගණන් kHz දක්වා. ඊට වැඩි frequencies වලට (kHz සිට සිය ගණන් MHz, උදා radio transmitters) LC oscillators තමයි ගැලපෙන්නේ, මොකද ඒ frequencies වලට ගැලපෙන L, C අගයන් පුංචි සහ ප්‍රායෝගිකයි.

  1. පටන් ගැනීම: Slide 2 දකුණු රූපයේ වගේ, මුලින් V source එකකින් C එක charge කරනවා. දැන් energy එක තියෙන්නේ C එකේ electric field (plates දෙක අතර තියෙන විද්‍යුත් ක්ෂේත්‍රය) එකේ.
  2. C discharge වෙනවා: Source එක අයින් කරලා C එක L එකට සම්බන්ධ කළාම, C එක L හරහා discharge වෙනවා. Current එක ගලද්දී L එක වටේ magnetic field (චුම්බක ක්ෂේත්‍රය) එකක් හැදෙනවා. Energy එක දැන් L එකට මාරු වෙනවා.

Comparator (inputs දෙකක් සසඳලා output එක High හෝ Low කරන op-amp circuit එක) එකක් හරිම සරලයි: V1>V2V_1 > V_2 නම් output High, V1<V2V_1 < V_2 නම් output Low. Op-amp එකේ gain එක ගොඩක් ලොකු නිසා, inputs අතර පුංචිම වෙනසකටත් output එක supply එකේ උපරිමයට (VH) හෝ අවමයට (VL) යනවා.

Noise එක නිසා ප්‍රශ්නය (slide 1)

ඇත්ත signals වල හැමවෙලේම පුංචි noise (signal එකට එකතු වෙන අහඹු පුංචි කැළඹීම්) තියෙනවා. Input එක හෙමින් reference voltage එක පනිද්දී, noise එක නිසා ඒක reference එක වටේ උඩට පහළට කීප වතාවක් පනිනවා. ඒ හැම වතාවකම comparator output එක මාරු වෙනවා. ප්‍රතිඵලය: එක මාරු වීමක් වෙනුවට ඉක්මන් මාරු වීම් ගොඩක් (උඩ රූපයේ කහ). Digital circuit එකකට මේක "එක පාරක්" වෙනුවට "දහ පාරක්" වගේ පේනවා, ඒක ලොකු වැරැද්දක්.

Schmitt trigger එක කියන්නේ positive feedback එකක් එකතු කරපු comparator එකක්. ඒ feedback එක නිසා threshold එක output එක මොකක්ද කියන එක අනුව වෙනස් වෙනවා. ඒ නිසා thresholds දෙකක් ලැබෙනවා:

  • VUT (upper threshold point, උඩ සීමාව): input එක වැඩි වෙද්දී output එක මාරු වෙන්නේ මේක පැන්නම විතරයි.
  • VLT (lower threshold point, පහළ සීමාව): input එක අඩු වෙද්දී output එක ආපහු මාරු වෙන්නේ මේකට පහළට ගියාම විතරයි.
  • ඒ දෙක අතර පරතරය hysteresis (output එක තමන්ගේ කලින් තත්ත්වය "මතක" තියාගන්න කලාපය): H=VUT−VLTH = V_{UT} - V_{LT}.

එක පාරක් output එක මාරු වුණාට පස්සේ, ආපහු මාරු වෙන්න input එක hysteresis ප්‍රමාණයක් ආපස්සට යන්න ඕනේ. Noise එක hysteresis එකට වඩා පුංචි නම් ඒකට ඒක කරන්න බෑ. ඒ නිසා එක පිරිසිදු මාරු වීමක් විතරයි (උඩ රූපයේ නිල්).

Inverting Schmitt trigger

මෙතන input signal එක යන්නේ op-amp එකේ − (inverting) input එකට. + input එකට එන්නේ output එකෙන් R1, R2 voltage divider එක හරහා ගන්න කොටසක්. ඒක තමයි positive feedback එක: output එක + පැත්තට ආපහු යනවා.

V⁺ හොයමු (KCL)

V⁺ node එකට resistors දෙකක් සම්බන්ධයි: R1 ground එකට, R2 Vout එකට. Op-amp input එකට current යන්නේ නැති නිසා, R1 හරහා යන current එක + R2 හරහා යන current එක = 0:

  1. V+−0R1+V+−VoutR2=0\frac{V^+ - 0}{R_1} + \frac{V^+ - V_{out}}{R_2} = 0
  2. R1R2 වලින් ගුණ කරන්න:
    V+R2+V+R1−VoutR1=0V^+ R_2 + V^+ R_1 - V_{out} R_1 = 0
  3. V+=R1R1+R2 VoutV^+ = \frac{R_1}{R_1 + R_2}\, V_{out}

ඉතින් V⁺ (comparator එකේ threshold එක) Vout එකේ කොටසක්. Vout එකට තියෙන්නේ අගයන් දෙකයි (VH හෝ VL), ඒ නිසා thresholds දෙකක් ලැබෙනවා.

VUT සහ VLT

  1. Output එක High (VH) තියෙද්දී: V+=R1R1+R2 VHV^+ = \dfrac{R_1}{R_1 + R_2}\, V_H (ධන අගයක්). Vin මේකට වඩා අඩු තාක් කල් V⁻ < V⁺, output High. Vin මේක පැන්න ගමන් V⁻ > V⁺ වෙලා output එක Low වෙනවා. ඒ නිසා:
    VUT=R1R1+R2 VHV_{UT} = \frac{R_1}{R_1 + R_2}\, V_H
  2. Output එක Low (VL) තියෙද්දී: දැන් V+=R1R1+R2 VLV^+ = \dfrac{R_1}{R_1 + R_2}\, V_L (සෘණ අගයක්). Vin මේකට පහළට ගියාම output එක ආපහු High:
    VLT=R1R1+R2 VLV_{LT} = \frac{R_1}{R_1 + R_2}\, V_L
  3. Hysteresis=VUT−VLT=R1R1+R2 (VH−VL)\text{Hysteresis} = V_{UT} - V_{LT} = \frac{R_1}{R_1 + R_2}\,(V_H - V_L)

Loop එක දිහා බලන්න: input එක වැඩි වෙද්දී output එක High සිට Low යනවා. ඒ කියන්නේ input එකට විරුද්ධ දිශාවට. ඒ නිසා තමයි මේකට "inverting" කියන්නේ.

Non-inverting Schmitt trigger

Multivibrators: states දෙකක් තියෙන circuits

Multivibrator වර්ග, 555 pin diagram එක සහ block diagram එක decks 5 කම (MV Intro, Astable, Monostable, Bistable, VCO) නැවත නැවත එනවා. මෙතන (24, 25 කොටස්) එක වතාවක් විතරක් සම්පූර්ණයෙන් පැහැදිලි කරනවා.

මෙතෙක් බැලුවේ sine wave හදන oscillators. දැන් අපි non-sinusoidal (sine නොවන, square වගේ) waves පැත්තට යනවා. Multivibrator එකක් කියන්නේ states දෙකක් විතරක් තියෙන circuit එකක්: High සහ Low (උදා 15 V සහ 0 V). Output එක මේ දෙක අතර විතරක් පනිනවා, මැද අගයක් නෑ. Timers, oscillators, flip-flops වගේ two-state devices හදන්නේ මේවගෙන්. Op-amps, transistors හෝ 555 timer IC එකෙන් හදන්න පුළුවන් (slide 1).

Resistor එකක් හරහා charge හෝ discharge වෙන capacitor එකක voltage එක කාලයත් එක්ක මෙහෙම වෙනස් වෙනවා (මේකම 30 කොටසේ monostable එකටත් පාවිච්චි කරනවා):

VC(t)=VF+(VI−VF) e−t/RCV_C(t) = V_F + (V_I - V_F)\, e^{-t/RC}

VIV_I = පටන් ගන්න voltage එක, VFV_F = C එක යන්න හදන අවසාන voltage එක (ඒ කියන්නේ කාලය අනන්තයක් ගියාම ලැබෙන අගය), RCRC = time constant (charge වීමේ වේගය තීරණය කරන අගය).

Bistable එකට stable states දෙකක් තියෙනවා: High සහ Low. Trigger එකකින් එකකින් අනිකට යනවා, ඊළඟ trigger එක එනකම් එතනමයි ඉන්නේ. ඒ කියන්නේ ඒක bit එකක් මතක තියාගන්නවා. ඒ නිසා flip-flop හෝ latch (අගුලක් වගේ තත්ත්වය "අගුළු දාලා" තියාගන්න circuit එක) කියනවා (slides 1–2).

VCO: voltage එකකින් frequency එක පාලනය කිරීම

VCO (Voltage Controlled Oscillator) එකක් කියන්නේ output frequency එක control voltage (පාලක voltage එක) එකකින් පාලනය වෙන oscillator එකක් (slide 2). Control voltage එක වැඩි කළාම (හෝ අඩු කළාම) frequency එක වෙනස් වෙනවා.

අදහස (slides 3–5)

මෙතෙක් බැලුව හැම oscillator එකකම frequency එක තීරණය වුණේ R, C හෝ L අගයන් වලින් (උදා RC: 12πRC6\dfrac{1}{2\pi RC\sqrt{6}}, LC: 12πLC\dfrac{1}{2\pi\sqrt{LC}}). ඒ components වලින් එකක් voltage එකකින් අගය වෙනස් වෙන එකක් කළොත්, voltage එකෙන් frequency එක පාලනය කරන්න පුළුවන්. ඒක තමයි VCO එක.

ප්‍රායෝගිකව: microcontroller එකක් digital අංකයක් DAC (digital-to-analog converter: digital අංකය voltage එකක් කරන circuit එක) එකකට යවනවා → ඒකෙන් Vcontrol → VCO එක (slide 5). එතකොට software එකෙන් frequency එක වෙනස් කරන්න පුළුවන්.

Applications සහ වර්ග (slides 6–7)

  • Phase-locked loop (PLL) (input signal එකක frequency එකට තමන්ගේ frequency එක "lock" කරගන්න circuit එක)
  • Modulation / demodulation (FM radio වල frequency modulation)
  • Frequency synthesizers (radio, phones වල නියම frequencies හදන්න)
  • Function generators (lab එකේ signal generator)

VCO වර්ග දෙකක්: harmonic (sine: RC, LC, crystal) සහ relaxation (square/triangle, 35 කොටස). 7 කොටසේ oscillator වර්ග tree එකම තමයි.

LC VCO: varactor diode (slides 8–10)

LC tank එකේ C1, C2 වෙනුවට back-to-back varactor diodes D1, D2 දානවා (උඩ රූපය). Varactor එකක් කියන්නේ reverse bias කළාම capacitor එකක් වගේ හැසිරෙන diode එකක්. Reverse bias කළාම diode එක ඇතුළේ depletion layer (current යන්නේ නැති, capacitor එකක plates අතර ඉඩ වගේ කලාපය) එකක් හැදෙනවා:

Supply pushing සහ load pulling (slides 25–26)

  • Supply pushing (Hz/V): Power supply voltage එක වෙනස් වෙද්දී output frequency එක වෙනස් වීම. 20 කොටසේ "supply voltage නිසා f වෙනස් වීම" මතකද? ඒක මනින්නේ මේකෙන්. අඩු වෙන තරමට හොඳයි.

Spectral purity: jitter සහ phase noise (slides 27–30)

Ideal VCO එකක output එක හරියටම f0 frequency එකේ, වෙලාවට නියමිත edges. ඇත්ත VCO එකක noise නිසා ඒක ටිකක් අපිරිසිදුයි. ඒක මනින විදි දෙකක්:

  • Time domain: jitter (square wave එකේ edges එන වෙලාව අහඹු ලෙස ටිකක් ඉස්සරහට පස්සට සෙලවීම).
  • Frequency domain: phase noise: Ideal output එක spectrum එකේ f0 ට එක සිහින් ඉරක්. ඇත්තටම f0 වටේ "skirt" (ගවුමක පහළ කොටස වගේ පැතිරුණු හැඩයක්) එකක් තියෙනවා. f0 + Δf offset එකක 1 Hz bandwidth එකක power එක, carrier (f0) power එකට සාපේක්ෂව මනිනවා. Unit එක dBc/Hz (dB relative to carrier, per Hz). Offset එක වැඩි වෙද්දී phase noise එක අඩු වෙනවා (slide 29: −60 සිට −155 dBc/Hz දක්වා).
