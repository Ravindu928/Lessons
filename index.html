Oscillator මූලික: DC එකෙන් AC wave එකක්

එකතු කළේ: Intro deck එක මුළුමනින්ම + LC/RC decks වල නැවත එන Barkhausen slides + VCO deck එකේ "oscillator" හැඳින්වීම.

Oscillator (දිගටම පැද්දෙන wave එකක් හදන circuit එක) එකකට AC input signal එකක් ඕනේ නෑ. DC power supply එකේ energy එක අරගෙන AC wave එකක් හදනවා. Frequency එක Hz සිට GHz දක්වා (phone, ඔරලෝසුව, radio, computer clock). Frequency එක තීරණය කරන්නේ circuit එක ඇතුලේ තියෙන R, C, L අගයන් (VCO slide 3).

T = 1/f  (T = period: එක වටයකට යන කාලය)

⚠ සැලකිය යුතුයි: Intro slide 1 සහ VCO slides 3–4 වල input එක "DC Signal / DC Voltage" කියලා තියෙනවා. ඒක signal එකක් නෙවෙයි, DC power supply එකක්. Exam එකේ "DC supply එකේ energy එක AC signal එකක් බවට හරවනවා" කියලා ලියන්න.

Block diagram සහ gain සූත්‍රය

Oscillator = amplifier (A) (signal එක ලොකු කරන කොටස) + feedback network (β) (output එකෙන් කොටසක් ආපහු යවන කොටස) + Σ (එකතු කරන තැන). Σ එකේ ලකුණු දෙකම + නිසා මේක positive feedback (ආපහු එන කොටස input එකට එකතු වෙනවා). Mic එක speaker එක ළඟට ගියාම එන "කීඊඊ" සද්දය හරියටම මේකයි.

  1. Vf = β·Vout
  2. Vout = A(Vin + Vf) = A·Vin + Aβ·Vout
  3. Vout(1 − Aβ) = A·Vin  →  Af = Vout/Vin = A / (1 − Aβ)

Aβ = loop gain (loop එක වටේ එක වතාවක් ගියාම signal එක කී ගුණයක් වෙනවද). Aβ = 1 නම් පහළ කොටස 0, Af = ∞: input නැතුවම output එකක්. ඒක තමයි oscillator එක. (Negative feedback නම් Af = A/(1 + Aβ), කවදාවත් ∞ වෙන්නේ නෑ.)

⚠ සැලකිය යුතුයි: Intro slide 3 එකේ Vout = A·Vin කියලා තියෙන්නේ පළමු වටයට විතරයි. Derivation එකට ඕනේ slide 9 එකේ Vout = A(Vin + Vf).

Aβ < 1, = 1, > 1

  • Aβ < 1: හැම වටයකම අඩු වෙනවා → මැකිලා යනවා (damped).
  • Aβ = 1: එකම ප්‍රමාණයෙන් දිගටම (sustained).
  • Aβ > 1: ලොකු වෙනවා → ±Vcc ට වැදිලා කැපෙනවා (clipping).

Af / A = 1/(1 − Aβ) = 20

Barkhausen criteria

Sustained oscillation එකකට කොන්දේසි දෙකම එකවර (Intro 6, 9 · RC 2 · LC 6):

|Aβ| = 1   සහ   ∠Aβ = 0° හෝ 360°

සාමාන්‍යයෙන් amplifier එක inverting (180°), ඉතින් β network එක 180° දෙන්න ඕනේ (RC phase shift, Colpitts, Hartley). Non-inverting (0°) නම් network එක 0° (Wien). Network එක R, C, L වලින් හදපු නිසා හරි phase එක ලැබෙන්නේ එක frequency එකකට විතරයි → ඒක තමයි f₀.

RC Phase Shift Oscillator

Inverting op-amp (180°) + CR stages 3ක network එක (180°) = 360°.

එක CR stage එකක් (slide 3)

Series C, ground එකට R. Output එක R හරහා. මේක voltage divider (voltage එක කොටස් දෙකකට බෙදන) එකක්:

Vo/Vin = R/(R − jXc) = 1/(1 − j/ωCR)  →  φ = tan⁻¹(Xc/R) (lead),  |Vo/Vin| = cos φ

φ කවදාවත් 90° ට ළඟා වෙන්නේ නෑ (90° = f → 0, output 0). ඉතින් stages 2ක් මදි, අවම stages 3 (slides 4–5).

Op-amp circuit එක (slides 7–9)

Derivation: √6 සහ 29 (slides 10–21)

Output එකේ සිට ආපස්සට, Ohm + KCL (node එකකට එන current = යන currents එකතුව). කෙටි කරන්න a = 1/(jωCR):

  1. I3 = Vo/R →
    V2 = Vo + I3/(jωC) = Vo(1 + a)
  2. KCL at V2:
    I2 = V2/R + I3 = (Vo/R)(2 + a)
  3. V1 = V2 + I2/(jωC) = Vo(1 + 3a + a²)
  4. KCL at V1:
    I1 = V1/R + I2 = (Vo/R)(3 + 4a + a²)
  5. Vin = V1 + I1/(jωC) = Vo(1 + 6a + 5a² + a³)
    a² = −1/(ωCR)², a³ = −1/(j(ωCR)³) දාන්න:
    Vin/Vo = [1 − 5/(ωCR)²] + (1/j)[6/(ωCR) − 1/(ωCR)³]
  6. 180° වෙන්න imaginary = 0:
    6(ωCR)² = 1 → ω = 1/(√6·RC) → f = 1/(2πRC√6)
  7. Real කොටස:
    Vin/Vo = 1 − 5×6 = −29 → β = −1/29 → |A| ≥ 29, Rf ≥ 29R1

Schmitt Trigger: hysteresis තියෙන comparator

Comparator එකේ ප්‍රශ්නය (slides 1–2)

Comparator (inputs දෙක සසඳලා output එක High හෝ Low කරන op-amp): V1 > V2 → High, V1 < V2 → Low. Input එකේ noise තියෙනකොට V2 ළඟදී output එක ගොඩක් වතාවක් වැරදියට මාරු වෙනවා (slide 1 waveform). විසඳුම: threshold දෙකක් (slide 2):

  • VUT (upper threshold): input එක මේක පනිද්දී output Low → High.
  • VLT (lower threshold): input එක මේකට පහළට යද්දී High → Low.
  • අතර තියෙන පරතරය hysteresis (output එක "මතක" තියාගන්න කලාපය) = VUT − VLT. Noise එක මේකට වඩා පුංචි නම් වැරදි මාරු වීම් නෑ.

Inverting Schmitt trigger (slides 3–5)

Vin → − input. R1 (ground) සහ R2 (Vout ට) + input එකට positive feedback දෙනවා. V+ node එකේ KCL:

  1. (V⁺ − 0)/R1 + (V⁺ − Vout)/R2 = 0 → V⁺ = R1/(R1+R2) · Vout
  2. Vout = VH නම්: V⁺ = R1/(R1+R2)·VH. Vin මේක පැන්නම → Vout = VL. ඉතින්
    VUT = R1/(R1+R2) · VH
  3. Vout = VL නම්: Vin මේකට පහළට ගියාම → VH:
    VLT = R1/(R1+R2) · VL
  4. Hysteresis = R1/(R1+R2) · (VH − VL)

Non-inverting Schmitt trigger (slide 6)

Vin → R1 → + input, R2 feedback, − input ground. Superposition/KCL:

  1. V⁺ = R2/(R1+R2) · Vin + R1/(R1+R2) · Vout
  2. V⁺ > 0 → VH, V⁺ < 0 → VL. Vout = VL තියෙද්දී V⁺ = 0 වෙන තැන:
    VUT = −(R1/R2) · VL
  3. Vout = VH තියෙද්දී:
    VLT = −(R1/R2) · VH
  4. Hysteresis = (R1/R2)(VH − VL)

t1, t2 derivation (slides 12–13, 18–21)

Capacitor සූත්‍රය (මේකම §8 monostable එකටත්): Vc(t) = VF + (VI − VF)·e^(−t/RC) (VI = පටන් ගන්න voltage, VF = යන්න හදන අවසාන voltage).

  1. High (charge): VI = ⅓Vcc, VF = Vcc, R′ = R1 + R2. Vc = ⅔Vcc වෙන කාලය t1:
    ⅔Vcc = Vcc − ⅔Vcc·e^(−t1/R′C) → e^(−t1/R′C) = ½ → t1 = ln2·R′C
    t1 = 0.693 (R1 + R2) C
  2. Low (discharge): VI = ⅔Vcc, VF = 0, R2 විතරයි (pin 7 ground):
    ⅓Vcc = ⅔Vcc·e^(−t2/R2C) → t2 = ln2·R2C
    t2 = 0.693 R2 C
  3. T = t1 + t2 = 0.693 (R1 + 2R2) C,   f = 1/T ≈ 1.44 / ((R1 + 2R2) C)
  4. Duty cycle D = t1/T = (R1 + R2)/(R1 + 2R2)
    → මේක හැම විටම > 50% (t1 ට R1 + R2, t2 ට R2 විතරයි).

50% duty cycle: diode එකක් (slides 14–17)

R2 ට parallel diode එකක් දැම්මම charge current එක R1 → diode හරහා (R2 bypass), discharge current එක R2 හරහා. ඉතින්:

t1 = 0.693 R1 C,   t2 = 0.693 R2 C,   D = R1/(R1 + R2)

R1 > R2 → D > 50%; R1 < R2 → D < 50%; R1 = R2 → 50%. R1 variable resistor එකක් නිසා duty cycle එක adjust කරන්න පුළුවන්.

555 Monostable Multivibrator (one-shot)

වැඩ කරන හැටි (slides 7–9)

  1. Stable state: Q = 0, output Low, discharge ON → C1 short, Vc ≈ 0.
  2. Trigger: pin 2 ⅓Vcc ට පහළට → S = 1 → Q = 1, output High, discharge OFF.
  3. C1 එක R1 හරහා 0 සිට Vcc දෙසට charge වෙනවා (unstable state).
  4. Vc = ⅔Vcc → R = 1 → Q = 0, Low, discharge ON → C1 ඉක්මනට discharge → ආපහු stable.

T = 1.1 R1C1 (slides 9, 12–13)

  1. VI = 0, VF = Vcc:
    Vc(t) = Vcc + (0 − Vcc)e^(−t/RC) = Vcc(1 − e^(−t/RC))
  2. ⅔Vcc = Vcc(1 − e^(−T/RC)) → e^(−T/RC) = ⅓ → T = RC·ln3
  3. T ≈ 1.1 R1 C1

Applications (slides 5, 10–11)

  • Timing delays: C1 = 10 µF, T = 1 s → R1 = 1/(1.1 × 10µ) = 90.9 kΩ ≈ 91 kΩ (slide 10).
  • Frequency division: output pulse එක (t) trigger period එකට (T) වඩා දිග නම්, pulse එක අතරතුර එන triggers ගණන් ගන්නේ නෑ → output frequency = trigger frequency / 2 (slide 11).
  • PWM (pulse width modulation: pulse එකේ පළල වෙනස් කිරීම) සහ relay switching.

Voltage Controlled Oscillator (VCO)

VCO = output frequency එක control voltage එකකින් පාලනය වෙන oscillator එක (slide 2). §1 වල කිව්වා frequency එක R, C, L අගයන්ගෙන් එනවා කියලා; ඒවායින් එකක් voltage එකකින් වෙනස් වෙන එකක් කළාම VCO එකක් (slides 3–4). Microcontroller → DAC (digital අංකය voltage එකක් කරන) → Vcontrol → VCO (slide 5).

Applications (slide 6): Phase-locked loop (PLL), modulation/demodulation (FM), frequency synthesizers, function generators. වර්ග (slide 7): harmonic (RC, LC, crystal) සහ relaxation (§1 tree එක).

LC VCO: varactor diode (slides 8–10)

Tank එකේ C1, C2 වෙනුවට back-to-back varactor diodes (reverse bias කළාම capacitor එකක් වගේ හැසිරෙන diode; reverse voltage වැඩි වෙද්දී capacitance අඩු වෙනවා) D1, D2. Vcontrol මැදට. Voltage ↑ → C ↓ → f ↑ (f ∝ 1/√LC).

⚠ සැලකිය යුතුයි: Slide 10 එකේ RC oscillator f ∝ 1/√(RC). වැරදියි: RC oscillators වල f ∝ 1/(RC) (§2, §3: 1/(2πRC√6), 1/(2πRC)). √ එක එන්නේ LC එකට විතරයි.

VCO characteristic (slides 11–12)

Vmin → fmin, Vmax → fmax අතර linear. V0 දී f0 (center / free-running frequency):

f(t) = f0 + K · Vc(t)  K = tuning gain (Hz/V)

Relaxation VCO (slides 13–17)

  1. IREF ∝ VTUNE current source එකක් C charge කරනවා → constant current නිසා Vc සෘජු රේඛාවක් (ramp) විදියට වැඩි වෙනවා.
  2. Vc Schmitt trigger (§5) එකට. Thresholds ±VREF.
  3. Schmitt output එකෙන් current දිශාව මාරු කරනවා (IREF / −IREF) → Vc +VREF සහ −VREF අතර triangle, output එක square.
  4. VTUNE ↑ → I ↑ → ramp ඉක්මන් → f ↑.

Lecture එකේ නැති අමතර දැනුම

එක ramp එකක් (−VREF → +VREF) = C·2VREF/I. Cycle එකට ramps දෙකක් → f = IREF / (4 C VREF). I ∝ V නිසා f ∝ V: linear VCO.
